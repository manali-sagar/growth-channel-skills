# Growth Channel Skills

Skills for planning growth and running acquisition channels in **freemium and subscription products**, built from the methods I use with clients at [Small Table Studio](https://manalihanamsagar.com/smalltablestudio?utm_source=github&utm_medium=readme&utm_campaign=growth-channel-skills).

Install them in Claude, bring your own numbers, and get a plan you can actually run: what your goal requires, which channels to start when, and how to set each one up.

**By Manali Hanamsagar**, growth operator and founder of Small Table Studio. 10+ years making growth channels work: paid social and search, affiliate, referral, and product-led growth.

Looking for activation, onboarding, and AI trust? See [PLG for AI Products](https://github.com/manali-sagar/plg-for-ai-products).

## The skills

| Skill | Use it when | What you get |
|---|---|---|
| [**growth-plan**](skills/growth-plan/SKILL.md) | You have a revenue target and need a channel plan, or need to know if the target is realistic | The honest math (required vs. plan vs. gap), a sequenced channel strategy, a RICE-scored experiment backlog, and a 90-day roadmap |
| [**referral-program-design**](skills/referral-program-design/SKILL.md) | You want to launch or fix a referral program | Referrer tracks, incentive design with unit economics, trigger sequences with draft messages, tracking setup, and an ops playbook |

More channel skills are on the way. Each includes the full method in `references/framework.md`, so you can also just read them.

## Install

### Claude.ai or the Claude desktop app
1. Download the skill you want from the [`downloads`](downloads) folder (each is a `.zip`).
2. In Claude, open **Settings → Skills** and upload the zip. Skills require a paid plan with code execution enabled.
3. Start a chat and ask, for example: *"Build a growth plan to get us to $1M ARR in 12 months"* and share your numbers.

### Claude Code
Install as a plugin from the Small Table Studio collection:

```
/plugin marketplace add manali-sagar/plg-for-ai-products
/plugin install growth-channel-skills@small-table-studio
```

Or copy any folder from [`skills`](skills) into `~/.claude/skills/`.

## How to get the most out of them

- **Bring your own numbers.** The skills work from your analytics, billing, and CRM data. They won't fill gaps with made-up benchmarks; they'll tell you what to measure.
- **Expect honesty about the gap.** If your target needs more than your channels can deliver, the plan will say so and show which assumptions would have to change.
